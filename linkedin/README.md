## How to publish

**Option A — document post (recommended, shows all 8 slides)**
1. LinkedIn → *Start a post* → *Add a document*.
2. Upload `carousel.pdf`, title it “CloudOps Sentinel — cloud operations platform”.
3. Paste the body text from `linkedin-post.md` (everything after the front-matter block).
4. Post.

**Option B — image post**
Upload `cover.png` (or `architecture.png` for a technical audience) and use the same body text.

## Post copy

`cloudops-sentinel/linkedin-post.md` opens with a short front-matter block (post type, asset names) followed by
`---`. Everything after that separator is the post body.
