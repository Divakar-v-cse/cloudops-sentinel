# Screenshots

Real captures of the running application, produced by `scripts/capture-screenshots.mjs` (Playwright, Chromium,
1600×960, full page). `manifest.json` records the route, page title, console errors and failed requests observed
for each capture — it is generated by the script, not written by hand.

## Reproduce

```bash
# terminal 1
cd backend && PYTHONPATH=. uvicorn app.main:app --port 8000

# terminal 2
cd frontend && npm install && npm run dev

# terminal 3 (Playwright is not a project dependency, to keep installs small)
npm install --no-save playwright
npx playwright install chromium
node scripts/capture-screenshots.mjs
```

Against another port or account:

```bash
BASE_URL=http://localhost:5173 EMAIL=engineer@cloudops.local PASSWORD='...' node scripts/capture-screenshots.mjs
```

## Notes

* The interface is a live dashboard, so numbers differ between captures — that is expected, not an edit.
* Screenshots always show simulated rows with a `simulated` badge. If a screenshot ever showed simulated data
  without that badge, it would be a defect.
* Large PNGs are acceptable in a repository but keep the set small (one per page). Re-capture after a UI change
  rather than committing outdated images.
